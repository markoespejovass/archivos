info:
  title: Know Your Customer
  description: |-
    This API manages the 'Know Your Customer' (KYC) process, a screening method used to determine whether a party is a risk and has the capacity to engage in activities such as money laundering or terrorist financing. Only local systems can send requests to the API and interact with the screening system.

    This API refers to the target of the KYC process as a 'party' or a 'customer'. The term 'party' encompasses all persons or organizations that require screening.

    The KYC process is handled as follows:
    1. Once the onboarding process for a new customer starts locally, the local system initializes the KYC process and provides the customer details.
    2. The screening system calculates the customer's preliminary risk score and documentary requirements.
    3. In the screening system, analysts review the information and can request that the local system provides updates to the KYC process. For example, the local system can add necessary documents to the process to allow the risk score to be updated.
    4. Once the final risk score is known, the local system can update the customer's screening information, including the Politically Exposed Person (PEP) indicator. The customer's questionnaire and risk results can also be submitted to a country-specific external system.

    The API can be used for:
    - KYC process initialization:
    >- Initiate the online onboarding for a new customer's KYC process.
    >- Update the online onboarding data for a new customer's KYC process.
    - KYC process updates:
    >- Update the metadata for a KYC process.
    >- Update the KYC questionnaire for a party.
    >- Update the analysis for a KYC process.
    >- Escalate the KYC analysis for a party.
    >- Update the screening information for a KYC process.
    - KYC resolution retrievals:
    >- Retrieve a KYC resolution's details.
    >- Retrieve the status of a KYC process.
    - KYC external services:
    >- Submit a customer's risk results to an external service.
    >- Submit a customer's completed KYC questionnaire to an external service.
    - KYC operation data analysis:
    >- Create Questionnaire Id
    >- Creates a link between a KYC questionnaire ID and an account or contract.
    >- Registration of PLD holder and beneficiaries for cross-checking with sanction lists
    >- Processes customer information, validates potential risk alerts, and determines the corresponding risk level.
    >- Download the PDF format of the questionnaire in base64
    >- Retrieve UPLD indicator of client and partners

        - Check if there is any record with HIT status; if so, assign risk A3 and complete the process. If not, continue.
        - Determine whether the client is new or pre-existing:
