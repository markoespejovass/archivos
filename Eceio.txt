  description: |-
    This API manages documents in the document management service.

    The API can be used to:
    - Submit the metadata for a document to be uploaded.
    - Retrieve a list of documents.
    - Retrieve a document's metadata.
    - Retrieve a list of a document's versions.
    - Update a document's metadata.
    - Update a document's version.
    - Download a document.
    - Remove a document.
    - Consolidate a document.

    post:
      operationId: updateDocumentVersion
      tags:
        - Document management
      summary: Updates a document's version.
      description: |-
        Updates the version for a specific document stored in the document management service. This operation submits the metadata for the new document version and returns the link where it can be uploaded.

        The document ID and updated basic metadata must be provided in the request body.

        The response includes a link to the document management service, the date and time when the link expires, and the document ID to be provided in order to upload the new document version. Depending on the provided client ID, client secret, and authorization bearer token, the link is either an intranet or Internet URL.

        To use this operation:
        1) Send a request containing the metadata for the new document version.
        2) Use the URL and document ID returned in the response to access the document management service and upload the new document version. The document is automatically scanned for malware during the upload.
      parameters:

      summary: Submits the metadata for a document to be uploaded.
      description: |-
        Submits the metadata for a document to be uploaded to the document management service.

        The requester app's details and the following document metadata must be provided in the request body:
        - Multipurpose Internet mail extensions (MIME) type format
        - Document file name
        - Document type code
        - List of document properties. A minimum of one property must be provided.

        To use this operation:
        1) Send a request containing the document metadata.
        2) Use the URL and document ID returned in the response to access the document management service and upload the document. The document is automatically scanned for malware during the upload.
