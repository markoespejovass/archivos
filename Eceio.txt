  title: Data Consent Management
  version: 7.1.0
  description: |-
    This API manages consent agreements for parties (persons or organizations) and contact points (communication methods by which parties can be contacted). Consent agreements give the bank permission to handle data from customers and other parties with whom they have a relationship.

    The API can be used for:
    - Consent agreements for parties:
      - Create a consent agreement for a party.
      - Retrieve a list of consent agreements for a party.
      - Update a consent agreement's details for a party.
    - Consent agreements for contact points:
      - Create a consent agreement for a contact point.
      - Retrieve a list of consent agreements for a contact point.
      - Update a consent agreement's details for a contact point.
    - Consent relationships:
      - Create a consent relationship.
      - Retrieve a list of consent relationships.
