    This API manages customer benefit programs and their associated benefit packages.

    The API can be used for:
    - Benefit programs:
      - Create a benefit program.
      - Retrieve a list of benefit programs.
      - Retrieve a benefit program's details.
      - Update a benefit program's details.
      - Retrieve a benefit program's history.
      - Retrieve a list of available products for a benefit program.
      - Check a customer's benefit program eligibility.
      - Simulate a customer's contract for a list of benefit programs.
      - Register a customer in a benefit program.
    - Benefits:
      - Retrieve a list of benefits for a benefit program.

        PATCH /categories/UP

        {
          "key": "43362687",

          "tier_expires_at": "2050-01-01"
        }

        {
          "tier": {
            "key": "43362687",
            "tier_id": 3,
            "tier_expires_at": "2050-01-01"
          }
        }

        PATCH /categories/DOWN

        {
          "key": "43362687",

        Response:
        
        {
          "tier": {
            "key": "43362687",
            "tier_id": 1,
            "tier_expires_at": null
          }
