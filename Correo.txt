para emailboxes
para el get emailboxes/{emailbox_id}/send_email
para un error de no authorizado es 401
si no manda correo(campo emailAddress)  error de 400
si manda un correo(campo emailAddress) no valido 409
para un error interno 500 
el path param emailbox_id puede tomar los valore otp o cualquier otro de bd si no esta en bd se devolvera error 409, con el mensaje flujo de correo no soportado
de no enviarse el path param emailbox_id se devuelve error 404 (por gateway)

para post emailboxes/{emailbox_id}/emails/{email_id}/classify_email
el path param emailbox_id solo puede tomar los valore otp y el path param email_id solo puede asumir un valor de cadena de 6 caracteres y todo numericos en cualquier otro caso se devuelve error 409
si no se envia path param emailbox_id o path param email_id deuelve error 404(por gateway)
