description: |-
  Envía un correo electrónico desde un buzón específico para entregar un reporte de actividad a un cliente. Esta operación solo puede ser utilizada por personal de Santander.

  Para realizar la solicitud, se debe proporcionar el identificador del buzón (emailbox_id) en el path.

  En el cuerpo de la solicitud se debe enviar:
  - Información del usuario que envía el correo.
  - Identificador del centro desde el cual se envía el correo.
  - Identificador del reporte.
  - Información del correo electrónico.

  #### Validaciones

  | Validación | Código HTTP | Descripción |
  |------------|-------------|-------------|
  | No se envía el token de autenticación o es inválido. | 401 | Unauthorized |
  | No se envía el campo `emailAddress`. | 400 | Bad Request |
  | El campo `emailAddress` tiene un formato inválido. | 409 | Conflict |
  | El `emailbox_id` no corresponde a `otp` ni a un flujo de correo configurado. | 409 | Flujo de correo no soportado. |
  | Ocurre un error interno durante el procesamiento de la solicitud. | 500 | Internal Server Error |

  Si no se envía el parámetro de ruta `emailbox_id`, el API Gateway devolverá un HTTP 404 (Not Found).

  La respuesta incluye el identificador del correo enviado.
